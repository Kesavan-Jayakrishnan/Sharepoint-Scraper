# BlazorTodoApp

A basic Blazor Server app with Todo functionality. Users can add, display, and remove todo items.

## How to Run

1. Make sure you have the .NET SDK installed.
2. Open a terminal in the project directory.
3. Run:
   ```
dotnet run --project BlazorTodoApp
   ```
4. Open the provided localhost URL in your browser.

## Features
- Add new todo items
- Display todo list
- Remove todo items

---
This is a minimal sample. You can extend it with authentication, persistent storage, or more advanced features as needed.
